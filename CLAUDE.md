# Nova Prime 3D

Site vitrine estático (HTML/CSS/JS, sem build) da Nova Prime 3D. Veja o README para a estrutura.

## Padrões do projeto
- Ao criar ou redesenhar páginas, sites, landing pages, dashboards e interfaces, use sempre a skill `frontend-design` (`.claude/skills/frontend-design`).
- Assets visuais (banners, imagens de categoria, ilustrações) devem ser gerados com o MCP do Higgsfield e salvos em `assets/`. Fotos de produtos continuam vindo da Shopee.
- Mantenha o site estático: sem frameworks nem etapa de build, salvo pedido do dono.
- Idioma da interface e dos textos: português do Brasil.
